# 📚 PZM図書館（pzm-library）

図書の **貸出管理・掲示板・チャット問い合わせ** をひとつにまとめた図書館 Web アプリです。
画面・通知は **日本語 / 韓国語** に対応しています。

## 🔑 テストアカウント

| 区分 | メールアドレス | パスワード |
|---|---|---|
| 管理者 | `admin@example.com` | `Test1234!` |
| 一般会員 | `guest@example.com` | `Test1234!` |

画面右上の **日本語 / 한국어** で言語を切り替えられます。

## 🛠 使用技術

| 分類 | 技術 |
|---|---|
| Backend | Java 17, Spring Boot 4.0, MyBatis |
| Frontend | Thymeleaf, HTML / CSS, JavaScript |
| Database | MySQL 8 |
| リアルタイム | WebSocket（チャット） |
| その他 | Spring Mail（メール認証）, BCrypt（パスワード暗号化）, Kakao Book API（図書検索）, `@Scheduled`（返却期限通知）|

## ✨ 主な機能

### 会員
- メール認証付きの新規登録（ニックネーム重複チェック）
- ログイン / ログアウト（セッション）、パスワードは BCrypt で保存

### 図書・貸出
- 管理者が **Kakao Book API** で本を検索して登録（冊数を指定）
- 貸出の流れ: **申請 → 管理者が承認 → 延長（1回・7日）→ 返却**
- 貸出ルール: 1人5冊まで / 同じ本の重複申請不可 / 延滞中は申請不可
- 延滞して返却すると、**遅れた日数分だけ貸出停止**
- 紛失処理（管理者が理由を入力）

### 通知・チャット
- 毎朝9時に **返却期限の通知**（3日前・前日・当日・延滞）を自動送信
- 承認・延長・返却・紛失などのお知らせを自動送信
- 会員と管理者の **1:1 チャット（WebSocket）**、未読バッジ表示

### 掲示板
- お知らせ（管理者のみ）/ 自由掲示板
- 画像添付（最大5枚）、コメント・返信、閲覧数、検索・ページング

### 管理者
- ダッシュボード（承認待ち・貸出中・延滞・本日の返却・紛失・会員数）
- 会員管理（検索・ページング・貸出状況・停止状態の確認）
- 貸出管理、登録図書・所蔵本ごとの履歴、紛失図書一覧

### 多言語対応（i18n）
- 画面の文言を `messages.properties` に分離し、`LocaleResolver` で切り替え
- 会員ごとに言語を DB に保存し、**通知もその会員の言語で作成**

### REST API
- 図書・貸出・掲示板の API（掲示板は GET / POST / PUT / DELETE、ステータスコードを使い分け）

## 💡 設計で工夫した点

### 1. 「本」と「所蔵本」を分離
`books`（本の情報）と `book_copies`（実物1冊 = 1行）に分けました。
同じ本を複数冊持てるようにし、**1冊が紛失しても他の冊は貸出を続けられる** ようにしています。

### 2. 貸出状態を区分値で管理
`loans.status` を `1:申請 / 2:貸出中 / 4:返却済み / 5:紛失` の数値で管理し、CHECK 制約で不正な値を防いでいます。
（3「返却申請」は仕様変更で廃止したため欠番）

### 3. 紛失処理をトランザクションで
紛失処理では **貸出の終了・所蔵本の状態変更・紛失記録の追加** の3テーブルを更新するため、
`@Transactional` で途中で失敗したら全部取り消されるようにしました。

### 4. 通知の多言語化
通知は管理者の承認時や毎朝のスケジューラーなど、**受け取る会員がその場にいないタイミング** で作られます。
そのため会員ごとに言語（`members.lang`）を保存し、その言語で文章を作って保存しています。

### 5. 役割ごとにクラスを分離
- `NotificationService`（通知の文章を作る）と `MessageService`（保存・取得）を分離
- スケジューラー（いつ）/ Mapper（誰に）/ NotificationService（何を）に役割を分けています
